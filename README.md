# Assignment-1: Problem Solving with TypeScript & OOP

## Overview

This repository contains my solutions for the **Problem Solving with TypeScript & OOP** assignment. The tasks assess practical understanding of core TypeScript concepts including basic types, optional/default/rest parameters, readonly tuples, interfaces, type narrowing, generics, asynchronous Promises, and Object-Oriented Programming (OOP) principles like inheritance and access modifiers.

All coding problem solutions (Problems 1 through 8) are implemented with strict typing, clean code practices, and exact naming conventions inside a single file: `solutions.ts`.
